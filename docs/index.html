Digi21.WinUI.Docking

Documentation

Dockable tool windows with splitters and tabs, a tabbed MDI document area, Visual Studio-style dock guides, floating windows, auto-hide and layout serialization, for WinUI 3 applications.

  • Understanding the docking control tree Where a docking tree can be hosted, which elements a layout accepts, what the control templates build around them, and the rules the layout system enforces. Six runtime trees for the usual arrangements.
  • Theming ↗ Every brush and metric key the chrome paints with, how to redefine them for light, dark and high contrast, and how to retemplate a control.
  • Getting started ↗ Installation, a quickstart layout in XAML, and the API for documents, floating windows, auto-hide and saving the layout.
